# Бот проектов Cursor

Telegram-бот с меню проектов для облачных агентов Cursor. В чате можно выбрать проект, создать новый и отправить задачу агенту. Следующие сообщения в том же проекте продолжают тот же разговор.

Новый проект — это либо пустая среда без репозитория, либо уже подключённый к Cursor репозиторий. Бот не создаёт репозиторий на GitHub: pull request возможен только у проекта, к которому привязан существующий репозиторий.

## Что есть в меню

- Список ваших проектов с перелистыванием.
- Нижние кнопки «Проекты», «Новый проект» и «Статус».
- Создание проекта: пустой, из репозиториев GitHub, которые видит Cursor, или по ссылке.
- Задача текстом уходит в Cloud Agents API. Ответ приходит в тот же чат.
- Остановка текущей задачи и удаление проекта из меню. Агент в Cursor при удалении из меню не стирается.

Список репозиториев кэшируется: у этого метода Cursor жёсткий лимит, примерно один запрос в минуту.

## Запуск

Нужны Python 3.12 и токен бота от [@BotFather](https://t.me/BotFather).

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
cp .env.example .env
```

Заполните `.env`:

| Переменная | Зачем |
| --- | --- |
| `TELEGRAM_BOT_TOKEN` | Токен от BotFather |
| `CURSOR_API_KEY` | Ключ из Cursor Dashboard → API Keys. Без него бот работает в демо-режиме |
| `TELEGRAM_ALLOWED_USER_IDS` | Ваш числовой Telegram id, через запятую, если ботом пользуетесь не один |
| `FORGE_DEMO` | `1`, чтобы не вызывать Cursor даже при заданном ключе |
| `DATABASE_PATH` | Файл SQLite, по умолчанию `data/bot.sqlite` |

Узнать свой id можно у [@userinfobot](https://t.me/userinfobot).

```bash
python -m projectbot
```

Бот должен продолжать работать, пока вы переписываетесь. Остановка процесса прерывает ожидание ответа; после следующего запуска бот дочитывает незавершённые задачи.

В демо-режиме меню, создание проектов и ответы-заглушки работают без ключа Cursor. Облачный агент при этом не стартует.

## Команды

- `/start` — приветствие и список проектов
- `/projects` — тот же список
- `/new` — новый проект
- `/status` — выбранный проект
- `/cancel` — прервать создание
- `/help` — краткая справка
